## 一句话行程

## 逐日详情

### D0 · 9/25（周五）杭州/上海 → 兰州
- **安排**：飞机抵达兰州，晚上集合
- **住宿**：凡里而美酒店（兰州老街西站店）· 9/25 入住 – 9/26 离店
- **吃**：早餐吃正宗兰州牛肉面（**马子禄 / 吾穆勒**）

### D1 · 9/26（周六）兰州 → 青海湖 → 茶卡盐湖 → 茶卡镇
- **里程 / 纯驾驶**：505 km · 6.9 h
- **计划时间**：8:30 出发 → 13:00 青海湖 → 15:00 离开 → 17:00 茶卡盐湖 → 18:30 离开 → 19:00 茶卡镇
- **会去**：兰州（出发）· 青海湖·二郎剑（门票约 100r）· 茶卡盐湖
- **住宿**：茶卡白兰道酒店（茶卡镇，离盐湖约 5km）· 9/26 – 9/27
- **备注**：必备防晒霜、墨镜、厚外套
- **⚠️ 提醒**：青海湖只有 2h（含午饭）、茶卡盐湖只有 1.5h，都偏短；建议 8:00 出发，或茶卡玩到 19:00（10 月初日落约 19:00）。**这一天海拔从兰州 1520m 升到青海湖 3200m，注意高反。**

### D2 · 9/27（周日）茶卡镇 → 大柴旦 → U型公路 → 东台 → 水上雅丹
- **里程 / 纯驾驶**：**629 km · 7.9 h（全程最硬的一天）**
- **计划时间**：8:00 出发 → 13:00 U型公路 → 15:00 水上雅丹 → 宿水上雅丹
- **会去**：大柴旦翡翠湖（日落最佳）· G315 U型公路（网红打卡，大货车多，别在路中间拍照）· 东台吉乃尔湖（部分干涸，顺路看一眼）· 乌素特水上雅丹（门票约 120r）
- **途经**：德令哈市、大柴旦镇
- **住宿**：孤独星际（戈壁）野奢酒店 · 9/27 – 9/28（地址：315 国道 894km 处南侧，**毗邻水上雅丹、紧接台吉乃尔湖**）
- **备注**：必备防水鞋套、湿巾；打卡镜面盐湖、尝青海老酸奶
- **⚠️ 提醒**：茶卡镇 → 大柴旦 **413 km 是绕不开的**（不管走高速还是走 315），加上后面三段共 629 km。**8:00 出发也要 19:00~19:30 才到**。建议 7:30 出门，大柴旦翡翠湖只留 1h（或直接放弃，把时间留给水上雅丹日落）。好消息是酒店订在水上雅丹，避开了「回大柴旦 340km 回头路 + 无人区夜路」。

### D3 · 9/28（周一）水上雅丹 → 西台吉乃尔湖 → 冷湖镇
- **里程 / 纯驾驶**：383 km · 4.6 h（**很松的一天**）
- **安排**：上午水上雅丹晨拍 → 西台吉乃尔湖 → 下午到冷湖镇（石油小镇）
- **住宿**：星穹秘境品质酒店（冷湖镇店）· 9/28 – 9/29
- **备注**：必下离线地图、全程满油；戈壁无信号
- **✅ 建议**：这天下午有富余，**建议先去黑独山踩点拍日落**（冷湖镇东北约 20km，顺路），把 D4 的压力挪过来。

### D4 · 9/29（周二）冷湖镇 → 火星一号公路 → 俄博梁 → 黑独山 → 敦煌
- **里程 / 纯驾驶**：**450 km · 9.3 h（现在全程最累的一天）**
- **会去**：俄博梁雅丹（**非铺装、无导航，需请向导，参考 500r/车**）· 黑独山（距冷湖镇约 20km，正好在去敦煌路上）
- **途经**：火星一号公路、当金山（青甘分界垭口）、阿克塞县（红柳湾镇）
- **住宿**：沙洲野奢营（敦煌月牙泉鸣沙山景区店）· 9/29 – 9/30
- **备注**：必喝李广杏皮水；晚上沙洲夜市驴肉黄面
- **❌ 提醒**：因为 9/28 宿在冷湖镇、**没有订冷湖火星营地**，俄博梁从「住一晚」变成了「冷湖镇起止的半日往返」（往返约 140 km 非铺装、4.5 h）。要么接受赶路、要么砍掉俄博梁只在火星一号公路口看外围雅丹——D3 下午有空，也可以把一部分提前。

### D5 · 9/30（周三）敦煌：莫高窟 + 鸣沙山月牙泉日落
- **里程 / 纯驾驶**：57 km · 1.2 h
- **会去**：莫高窟 · 鸣沙山·月牙泉（约 110r，日落最美）
- **住宿**：敦煌阿古拉设计师景观酒店（沙州夜市店）· 9/30 – 10/1
- **备注**：莫高窟 A 类票**提前 1 个月抢**；带防沙鞋套
- **⚠️ 提醒**：莫高窟在市区东 25km、鸣沙山在市区南，时间够。**A 类票国庆极难，现在就去预约。**

### D6 · 10/1（周四）敦煌 → 阳关 → 嘉峪关
- **里程 / 纯驾驶**：494 km · 6.0 h
- **计划时间**：8:30 出发 → 9:30 阳关 → 10:30 离开 → 16:00 嘉峪关
- **会去**：阳关（**在敦煌西南 70km，往返绕 140 km**）
- **顺路可加**：敦煌丝路遗产城、敦煌古城（都在去阳关的路上）
- **途经**：瓜州县
- **住宿**：全季酒店（嘉峪关迎宾湖店）· 10/1 – 10/2
- **备注**：随身携带身份证；晚餐嘉峪关烤羊肉串
- **⚠️ 建议**：建议 8:00 出发。**16:00 到嘉峪关后直接去关城**（市区西 6km，日落前光线最好），这样 10/2 就宽裕了。

### D7 · 10/2（周五）嘉峪关 → 金塔胡杨林 → 七彩丹霞
- **里程 / 纯驾驶**：321 km · 4.2 h
- **计划时间**：9:30 出发 → 18:00 到七彩丹霞
- **会去**：嘉峪关关城（约 110r）· 金塔沙漠胡杨林（约 85r）· 张掖七彩丹霞（约 93r，看日落）
- **顺路可加**：悬壁长城、长城第一墩（离关城 7~8km）· 瓜州 G30 路边的 大地之子 / 无界 / 汉武雄风
- **住宿**：公航旅·丹霞明珠酒店（七彩丹霞景区店）· 10/2 – 10/3
- **备注**：穿舒适登山鞋；尝张掖搓鱼面、张掖炒拨拉
- **⚠️ 提醒**：如果 10/1 下午已经玩了关城，这天 8:30 直奔金塔就舒服：金塔 10:30–12:30 → 七彩丹霞 16:30 到，正好赶上日落（10 月初约 19:00）。另外**金塔胡杨 10/2 可能才黄 2~4 成**，最佳在 10 月中。

### D8 · 10/3（周六）七彩丹霞 → 扁都口 → 阿柔大寺 → 阿咪东索 → 祁连县
- **里程 / 纯驾驶**：318 km · 4.7 h
- **计划时间**：6:00–9:00 七彩丹霞（日出）→ 10:00 出发 → 13:00 阿咪东索 → 17:00 离开 → 18:00 祁连县
- **会去**：张掖七彩丹霞（二次入园需在景区登记）· 阿柔大寺（就在峨堡→祁连路上，顺访即可）· 阿咪东索（牛心山，祁连县城南约 25km）
- **途经**：扁都口（G227 甘青要道，海拔约 3600m，**10 月可能降雪，出发前查路况**）
- **住宿**：祁连五矿国贸饭店 · 10/3 – 10/5（2 晚）
- **备注**：国庆野骑要**提前预定正规马场**、佩戴头盔手套、穿耐磨长裤；风大雨大即刻取消；晚餐手抓羊肉
- **⚠️ 提醒**：丹霞 → 祁连实际 **318 km / 4.7 h（不是 200km）**。10:00 出发算下来到阿咪东索约 14:40，「13:00」到不了。

### D9 · 10/4（周日）祁连县：卓尔山、阿柔大寺
- **里程 / 纯驾驶**：7 km · 0.2 h（**休整日**）
- **会去**：卓尔山（"东方小瑞士"，2~3h 足够）· 阿柔大寺
- **住宿**：祁连五矿国贸饭店（第 2 晚）
- **备注**：尊重寺庙礼仪，体验酥油茶
- **✅ 说明**：很松的一天。酒店就在卓尔山脚下、八宝河畔（前仰卓尔山、后倚牛心山），早上可以很早进景区避开国庆人流。

### D10 · 10/5（周一）祁连县 → 达坂山观景台 → 门源 → 西宁
- **里程 / 纯驾驶**：282 km · 3.6 h
- **安排**：09:00 出发 → 途经达坂山观景台、门源 → 西宁
- **途经**：达坂山（海拔 3792m）· 门源·浩门镇
- **住宿**：西宁富力万达文华酒店 · 10/5 – 10/6
- **备注**：提前检查车况胎压；晚餐莫家街酿皮、甜醅子
- **⚠️ 提醒**：建议 9:00 前出发。**达坂山 10 月可能结冰降雪**，出发前查路况；备选路线：祁连 → 刚察 → 青海湖北岸 → 西宁。

### D11 · 10/6（周二）西宁 → 兰州
- **里程 / 纯驾驶**：219 km · 2.6 h
- **安排**：西宁 → 兰州，下午到，**还车**，住一晚
- **住宿**：凡里而美酒店（兰州老街西站店）· 10/6 – 10/7
- **备注**：打卡牛奶鸡蛋醪糟
- **✅ 说明**：因为订单是 10/6 入住 – 10/7 离店，所以**返程日是 10/7**（原计划里写"10/6 返程"是笔误）。10/6 下午到兰州还能逛中山桥、正宁路夜市。

### D12 · 10/7（周三）兰州 → 返程
- **安排**：还车、登机/高铁返程
- **⚠️ 提醒**：兰州中川机场在市区北 60 km（约 1 h）。若是早班机，10/7 要 6:00 前出发；也可以 10/6 晚上先把车还掉。

## 文件结构 & 改什么改哪里

```
trip-map/
├── index.html              # 页面骨架 + 样式（改布局、图例文字看这里）
├── app.js                  # 地图逻辑：投影转换、标签避让、行程联动（改配色、避让参数看这里）
├── README.md               # ★ 本文件
└── data/
    ├── pois.js             # ★ 78 个点位：坐标 / 分类 / 名称 / 说明
    ├── itinerary.js        # ★ 逐日行程文字 + 计划体检结论
    ├── route.js            # 25 段实际路网轨迹（由 route.json 生成）
    ├── route.json          # OSRM 原始轨迹与里程
    └── geocode_raw.json    # Nominatim 地理编码原始返回
```

| 想改什么 | 改哪里 |
|---|---|
| 行程文字、每天的计划时间、住宿名、备注、风险提示 | `data/itinerary.js` |
| **加 / 删 / 改一个地点**（坐标、分类、名称、说明） | `data/pois.js` |
| **换酒店** | `data/pois.js` 里 `h_` 开头的条目（坐标 + 名称）+ `data/itinerary.js` 里对应天的 `stay` 和 `spots` |
| **改日期** | `data/itinerary.js` 的 `day` / `wd`；`data/route.js` 里每条 leg 的 `day` |
| 路线走向、里程 | `data/route.js`（或按下面的命令重拉 OSRM） |
| 分类颜色、标签避让参数 | `app.js` 顶部的 `CAT` / `LABEL_COLOR` / `RADII` |
| 表格内容（本 README） | 直接改本文件；**改完 `data/` 记得回来同步这里** |

### 示例 1：加一个地点

在 `data/pois.js` 对应分类里加一行：

```js
{id:'some_id', name:'完整名称', short:'地图上的短名', cat:'visit',
 lat:37.6188, lon:93.7507, day:'9/28', tip:'点开后显示的说明'},
```

- `cat` 取值：`visit` 会去 / `hotel` 酒店 / `pass` 途经 / `optional` 顺路可加 / `ref` 不去
- `dir`（可选）：想让名字固定朝某个方向，填 `right` / `left` / `top` / `bottom` / `tr` / `tl` / `br` / `bl`
- 坐标填 **WGS-84**（GPS/OSM 同款），不用手动做偏移
- 最后把 `id` 加进 `data/itinerary.js` 里那天的 `spots` 数组，点某天时才会一起高亮

### 示例 2：改日期

1. `data/itinerary.js`：改那天的 `day`（如 `'9/27'` → `'9/28'`）和 `wd`（星期几）
2. `data/route.js`：把当天所有 leg 的 `day` 改成同一个值（leg 靠 `day` 分组来算当天里程）
3. `data/pois.js`：如果那天的点位 `day` 字段也要跟着变
4. 本 README 的两张表同步一下

### 示例 3：换酒店

1. `data/pois.js`：找到 `h_xxxxx` 那条，改 `name` / `short` / `lat` / `lon` / `night` / `tip`
2. `data/itinerary.js`：改对应天的 `stay`（酒店全称 + 入住-离店日期）
3. 本 README 的「酒店清单」同步一行

### 示例 4：重拉路线（换路径或校正里程）

```bash
curl "https://router.project-osrm.org/route/v1/driving/99.11367,36.69173;95.36,37.8487?overview=full&geometries=geojson"
```

把返回的 `routes[0].geometry.coordinates` 作为 `path`，`routes[0].distance/1000` 作为 `km`，`routes[0].duration/60` 作为 `min`（坐标格式是 `[经度, 纬度]`）。

## 已知限制

- **里程是"理想值"**：`km` / `min` 由 OSRM 按道路限速算，不含休息、堵车、找车位。实际开车时间建议再留 **15~20%** 余量。
- **酒店坐标是估算的**：按携程/高德上的门店地址定位，误差在百米到一两公里级。用来判断"住在哪一片"足够，**导航以携程/高德为准**。
- **西台 → 冷湖那段里程以现场导航为准**：网上流传的 190 km 和 OSRM 算出的 340 km 差很多，不同地图给出的路线不一致。
- **少数小众点是近似坐标**（如黑马河、阿咪东索），用于示意。
- 页面依赖 CDN 和在线瓦片，**断网时底图会空白**（点位数据在本地，不受影响）。
