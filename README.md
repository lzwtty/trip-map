# 2026 国庆 · 青甘大环线 行程地图

一个单页的行程可视化地图：把这次青甘大环线自驾的**会去的景点、住哪家酒店、途经的城市、以及一份网上参考行程里"我们不去的点"**全部标在一张图上，用来核对路线顺不顺、每天要开多久。

- **行程**：2026-09-25 → 2026-10-07，13 天 12 晚，兰州进出
- **总里程**：约 **3666 km**（点对点实际路网距离，不含市内和景区内短途）
- **纯驾驶**：约 **51 小时**；最长的一天 9/27（629 km / 7.9 h）
- **点位**：78 个 —— 16 个会去景点 · 10 家已订酒店 · 22 个途经/停留 · 8 个顺路可加 · 22 个参考点（不去）

## 怎么看

用浏览器直接打开 `index.html` 就行，**不用装任何东西、不用起服务**。
（首次打开需要联网：Leaflet 从 CDN 加载，底图瓦片来自高德 / OpenStreetMap。）

左侧「每日行程」点任意一天，地图会飞过去并高亮当天的路段；「计划体检」是逐条列出的风险点和修改建议。

**底图可切**：高德·路网 / 高德·卫星 / OSM·路网。高德是 GCJ-02 坐标系、OSM 是 WGS-84，切换时页面会自动对所有点位做坐标转换。

**名称是引线式标注**：文字挂在旁边，由一条细引线 + 末端小圆点指回自己的位置。排布时先贴近点试，位置被占了就沿着「远离附近其它点」的方向一圈圈往外推（16→30→48→70→96→126 px），所以密集区域会自动呈放射状散开，不会糊成一团。

## 怎么改

### 加 / 改一个点位 —— `data/pois.js`

```js
{id:'some_id', name:'完整名称', short:'地图上显示的短名', cat:'visit',
 lat:37.6188, lon:93.7507, day:'9/28', tip:'点开后显示的说明'},
```

- `cat`：`visit` / `hotel` / `pass` / `optional` / `ref`
- `dir`（可选）：想让名字固定朝某个方向，填 `right` / `left` / `top` / `bottom` / `tr` / `tl` / `br` / `bl`
- 坐标用 **WGS-84**（和 OSM、GPS 一致）。页面显示高德底图时会自动转 GCJ-02，所以直接填 GPS 坐标就行，不用手动偏移
- 酒店用 `name` 放全称、`short` 放地图上的短标签，`night` 放住哪几晚

改完刷新页面即可。

### 改行程文字 —— `data/itinerary.js`

`ITINERARY` 是逐日卡片（`level` 决定左侧色条：`bad` 红 / `tight` 橙 / `ok` 绿 / `loose` 蓝），
`CHECKS` 是「计划体检」面板里的结论列表（`lv` 取 `bad` / `warn` / `info`）。

### 改路线走向 —— `data/route.js`

每条 leg 的结构：

```js
{day:'9/27', from:'chaka', to:'dachaidan', km:413.3, min:315,
 path:[[99.11367,36.69173], /* ... */ ]},
```

`path` 是 `[经度, 纬度]` 数组（WGS-84）。想换路线，两种办法：

1. **手改**：把 `path` 换成想要的折线坐标，`km` / `min` 顺便改一下。
2. **重拉真实路网**：向 OSRM 请求

   ```bash
   curl "https://router.project-osrm.org/route/v1/driving/99.11367,36.69173;95.36,37.8487?overview=full&geometries=geojson"
   ```

   把返回的 `routes[0].geometry.coordinates` 作为 `path`，`routes[0].distance/1000` 作为 `km`，`duration/60` 作为 `min`。

## 已知限制

- **里程是"理想值"**：`km` / `min` 由 OSRM 按道路限速算，不含休息、堵车、找车位。实际开车时间建议再留 15~20% 余量。
- **酒店坐标是估算的**：按携程/高德上的门店地址定位，误差在百米到一两公里级。用来判断"这一晚住在哪一片"足够，**导航请以携程/高德为准**。
- **西台 → 冷湖那段里程以现场导航为准**：网上流传的 190 km 和 OSRM 算出的 340 km 差很多，不同地图给出的路线不一致（见「计划体检」里的说明）。
- **少数小众点是近似坐标**（如黑马河、阿咪东索），用于示意。
- 页面依赖 CDN 和在线瓦片，**断网时底图会空白**（点位数据在本地，不受影响）。
